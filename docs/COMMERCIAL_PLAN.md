## 一、现状结论（基于代码审计）

产品本体（HUD、跨端编译、注入器、SkillForge、Skill Doctor）是真实可用的；**商业化层在 P0 之前基本是空壳**：

| 模块 | 审计时状态 |
|---|---|
| `src/pro/billing/licenseManager.ts` | 任何以 `SKILLDOCK-PRO-` 开头的 key 都能解锁终身 Pro；授权明文存 localStorage；正式校验地址在 Tauri 中不存在 |
| `src/pro/billing/paddleClient.ts` | 使用 Paddle Classic v1 写法，价格 ID 为占位符，跳转被注释，点击无反应 |
| `src/pro/sync/*` | 只记日志并返回 `success: true`，属于"假成功" |
| `src/pro/gateway/managedAiRelay.ts` | 返回写死字符串 |
| 付费墙 | `isProActive` / `hasProFeature` 未被任何组件引用，Free 与 Pro 无差别 |
| 许可证 | README 标注 MIT，但仓库无 LICENSE 文件 |

另一个已知的产品事实（见 `ROADMAP_A.md` 第二节）：Claude Code 官方支持当前会话内生效；其他工具以各自文档为准，产品主线是**跨工具规则治理**。

## 二、商业模式

**免费核心版拉新 → Pro 买断变现 → 有数据后再做 Team 订阅**

| 层级 | 价格 | 目标用户 | 买的是什么 |
|---|---|---|---|
| Community | 免费，开源 | 所有使用 AI 编程工具的开发者 | 看见、整理、一次性转译自己的规则 |
| Pro | $29 买断，含 1 年更新；早鸟 $19 | 同时用 2 个以上 AI 工具的个人开发者 | 省事、不出错、省 token |
| Team（暂缓） | 订阅制，待定 | 小团队 | 团队规则统一、下发、漂移检测 |

定价原则：
- 本地工具用买断；只有带来持续成本的服务（云同步、托管 AI）才订阅。
- "1 年更新"由授权中的 `updatesUntil` 字段加自动更新器执行，为续费升级留空间。
- 产品寿命受官方工具挤压的风险较高（见第五节），所以优先拿到前期现金。

### C. 砍掉或推迟

- **官方规约包客户端内置：彻底移除**，未来改为激活后服务端在线下发，客户端不内置任何规则包。
- **托管 AI 专线：砍掉。**有成本、有合规风险，坚持 BYOK。
- **R2 / Google Drive / 1Password 三套同步：合并为一套 Git 同步**（使用用户自己的私有仓库），零服务器成本，Team 版可复用。
- **Team 版：推迟**到付费个人用户超过 50 人。

### D. 收钱必需的非功能项

- Windows 代码签名（避免 SmartScreen 警告）、macOS 签名 + 公证
- Tauri 自动更新器（签名更新包，配合 `updatesUntil`）
- 自愿开启的匿名漏斗统计：下载 → 激活 → 完成导入 → 付费
- 许可证：核心 MIT；`src/pro/` 改为专有许可或迁出到私有仓库
- Landing Page、服务条款、隐私政策、退款政策（收款平台审核要求）
- 拆分超大组件：`DockOverlay.tsx`（约 2500 行）、`SkillForgeModal.tsx`（约 2550 行），加功能时顺手拆

## 四、收款渠道

**决策前必须先确认：中国大陆个人能否开户、能否提现。**这是整个计划的硬卡点。

| 平台 | 优点 | 待确认 |
|---|---|---|
| Paddle | MoR，处理全球税务 | 个人卖家审核；无原生 license key，需要自建 Webhook 签发 |
| Lemon Squeezy | MoR，自带 license key 与激活数限制 | 大陆个人提现支持情况 |
| Polar.sh | MoR，面向开源开发者，自带 license key | 提现依赖 Stripe Connect，大陆个人可能不支持 |

在决定之前，客户端结账保持与平台无关（P0 已按此实现：只打开一个可配置的 URL）。

## 七、阶段与止损标准

| 阶段 | 时间 | 目标 | 判断标准 |
|---|---|---|---|
| 0 | 第 1–2 周 | 商业化底座可信、新用户 5 分钟内看到价值 | P0 验收通过；导入向导能处理常见规则文件 |
| 1 | 第 3–5 周 | 免费版发布 + 预售 | **预售少于 20 单 → 停止加功能，重新调整定位** |
| 2 | 第 6–10 周 | Pro 功能上线、Product Hunt | 付费转化率、退款率 |
| 3 | 视数据 | Team 版 | 付费个人用户 ≥ 50 |

收入预期（保守）：前 3 个月按每月几百美元计划，不按报告中的 2.5% 转化率测算。开源工具从下载到付费的转化率通常低于 1%。

- **2026-10-08 第一次复盘**：
  - 原计划把"预售"放在阶段 1，但预售依赖收款平台，而收款平台被"大陆个人提现资质"阻塞，所以**第 3 项提前到阶段 0 第一周**，与 P0 并行。
