SkillDocker 隐私政策

本政策自发布之日起生效 | 最后更新：2026 年 10 月 13 日 | 架构原则：本地优先 (Local-First)，零云端中转

1. 核心架构与隐私承诺

SkillDocker 客户端遵从「本地优先 (Local-First)」与「数据不出本地」的安全设计原则：

  • 代码与规则零上传：SkillDocker 客户端不会向我们或任何第三方托管服务器上传您的项目源代码、工程规则文件（CLAUDE.md、.cursorrules 等）或本地 Skill 内容。
  • BYOK 零中转直连：当您在客户端配置大模型 API Key（用于 AI 会诊或优化）时，API Key 仅安全保存在您本地操作系统的钥匙串/密钥环中。调用时由本地客户端直接向模型供应商（如 Anthropic、Google 等）官方接口发起 HTTPS 通信，不经过 SkillDocker 的任何中转代理。
  • 离线密码学校验：商业版许可证采用 Ed25519 签名算法在您本机完全离线进行验证，不需要在线定期汇报心跳或上传机器指纹。

2. 支付与交易数据处理

当您在线购买 SkillDocker Pro 授权时，结账过程由支付服务商 Paddle.com 统一承接。Paddle 将收集完成交易所必需的账单信息（如邮箱地址、支付信息、IP 地址与国家/地区）。SkillDocker 开发者不触碰、不存储您的信用卡卡号或支付凭证。在订单交付（人工签发密钥）与售后支持环节，仅依据 Paddle 交易记录（交易号、购买邮箱及所选版本）进行处理。

3. 本地日志与诊断信息

为了便于本地调试与错误排查，客户端可能在本地计算机的数据目录中记录运行时日志（日志已做敏感信息自动脱敏处理，API Key 与密钥会被自动截断打码）。所有日志严格保存在本地，软件绝不会在后台静默自动上传日志文件。

4. 数据的留存与权利

因为 SkillDocker 不在云端集中存储您的用户数据，删除本地数据仅需通过常规卸载软件并清理本地配置目录即可完全清除。关于在 Paddle 处留存的交易发票记录，您可以根据 GDPR、CCPA 或相关法律行使查阅与更正权利。

5. 隐私事宜联络

如对本隐私政策或个人数据处理有任何疑问，请联系：support@skilldocker.com
