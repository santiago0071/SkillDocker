SkillDocker 退款政策

本政策自发布之日起生效 | 最后更新：2026 年 10 月 13 日

1. 退款受理方式

SkillDocker Pro 商业授权的收款与退款由支付服务商 Paddle.com 负责统一受理与执行。所有退款申请在批准后将直接原路返还至您最初结账时使用的支付账户。

2. 适用期限与条件

自购买之日起 14 天内可申请全额退款，无需说明理由。超过 14 天不予受理（不影响适用法律赋予的不可排除的法定权利）。

3. 不适用退款的情形

  • 自购买之日起已超过 14 天的退款申请（适用法律赋予的不可排除的法定权利除外）；
  • 由于用户自行配置的第三方大模型 API Key 余额不足、欠费、被模型供应商封禁或限流所导致的 AI 功能不可用（此部分属于第三方服务范畴，SkillDocker 采用纯本地 BYOK 机制，不中转、不承担第三方 API 费用）；
  • 用户存在严重违反法律法规或服务条款的行为（如未经授权转售授权密钥、反向工程等）。

4. 退款后的授权状态变动

退款申请获得批准并执行后，您所获得的 SkillDocker Pro 商业授权许可即行终止。鉴于 SkillDocker 客户端采用完全离线的本地密码学验签机制，目前不存在远程吊销密钥或强制客户端自动回退的技术机制。退款完成后，用户应依诚实信用原则及服务条款停止在客户端中继续使用该授权密钥，并自行将其移除。免费的社区版基础功能不受影响，仍可继续使用。

5. 如何申请退款

如需申请退款，请提供您的 Paddle 订单交易号（格式如 txn_... 或发票编号）及结账邮箱，通过以下渠道提交：

  • 渠道 A（Paddle 官方买家支持）：访问您的 Paddle 电子发票邮件中的支持链接；
  • 渠道 B（产品售后邮箱）：发送邮件至 support@skilldocker.com；
